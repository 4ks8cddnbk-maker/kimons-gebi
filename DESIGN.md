# DESIGN.md

## Projektvision
Die Website soll sich wie ein authentisches Smartphone-Betriebssystem der frühen 2010er-Jahre anfühlen. Der Fokus liegt auf maximaler Authentizität, einer glaubwürdigen Benutzeroberfläche und einer konsequenten Nachbildung der damaligen Designphilosophie.

## Designprinzipien
- Authentizität vor Modernisierung
- Skeuomorphes Design statt Flat Design
- Hohe Detailtreue
- Konsistente visuelle Sprache
- Spielerische Navigation
- Klare Informationshierarchie

## Visuelle Sprache
- Glänzende Oberflächen
- Realistische Lichtreflexe
- Weiche Verläufe
- Plastische Elemente
- Dezente Schatten
- Mehrere Tiefenebenen

## Farbwelt
- Kräftige, gesättigte Farben
- Dunklere Systembereiche
- Kontrastreiche Icons
- Leuchtende Akzentfarben

## Hintergrund
- Hochauflösender Wallpaper
- Ruhige Bildsprache
- Ausreichender Kontrast
- Keine modernen Blur-Effekte
- Keine dynamischen Hintergründe

## Statusbereich
- Fester oberer Bereich
- Uhrzeit und Systeminformationen
- Dunkler Verlauf
- Dezente Lichtreflexe
- Präzise Ausrichtung

## Raster
- Strenges Icon-Raster
- Einheitliche Abstände
- Konsistente Positionierung
- Mehrere Seiten möglich
- Horizontale Navigation zwischen Seiten

## Symbole
- Quadratische Grundform
- Starke Abrundungen
- Glänzende Oberfläche
- Licht- und Schattenebenen
- Individuelle Farbidentität
- Hohe Wiedererkennbarkeit

## Beschriftungen
- Kurze Titel
- Zentrierte Ausrichtung
- Einheitliche Typografie
- Hoher Kontrast

## Unterer Navigationsbereich
- Dauerhaft sichtbar
- Halbtransparente Oberfläche
- Glasartige Wirkung
- Eigener Schattenwurf
- Hervorgehobene Kernbereiche

## Animationen
### Seitenwechsel
- Flüssige horizontale Bewegung
- Gleichmäßige Geschwindigkeit

### Öffnen
- Leichte Vergrößerung
- Sanftes Einblenden

### Schließen
- Umgekehrte Animation
- Rückkehr zur Ausgangsposition

## Typografie
- Systemnahe Schriftwirkung
- Hohe Lesbarkeit
- Klare Hierarchie
- Kleine Beschriftungen
- Mittlere Navigation
- Große Überschriften

## Inhalte
- Mehrere eigenständige Bereiche
- Einheitliche Navigation
- Konsistentes Erscheinungsbild
- Klare Struktur

## Sounddesign
Optional:
- Klickgeräusche
- Navigationsfeedback
- Kurze Systemklänge

Anforderungen:
- Dezent
- Abschaltbar
- Nicht aufdringlich

## Technische Umsetzung
### Frontend
- HTML
- CSS
- JavaScript

### Architektur
- Komponentenbasiert
- Wiederverwendbare UI-Elemente
- Trennung von Layout und Inhalten

### Performance
- Optimierte Assets
- Kurze Ladezeiten
- Flüssige Animationen

## Benötigte Assets
- Hintergrundbild
- Symbolgrafiken
- Oberflächenstrukturen
- Licht- und Glanzeffekte
- Systemelemente
- Optionale Soundeffekte

## Qualitätskriterien
Das Ergebnis ist erfolgreich, wenn:
- Die Oberfläche sofort an ein mobiles Betriebssystem der frühen 2010er erinnert.
- Die Illusion einer echten Benutzeroberfläche entsteht.
- Moderne Designtrends vermieden werden.
- Alle Bereiche visuell konsistent wirken.
- Interaktionen natürlich erscheinen.
